# Guide d'utilisation - PASCI Mobile

Ce guide est destiné aux utilisateurs finaux de l'application mobile PASCI.

## 1) Démarrage

1. Ouvrir l'application PASCI
2. Naviguer via les onglets en bas de l'écran
3. Utiliser les écrans dédiés pour consulter les contenus et interagir

## 2) Navigation principale

- Accueil: chiffres clés, accès rapide
- Annuaire: CRASC, OSC, PTF
- Espace collaboratif: pôles, sujets et échanges
- Projets/emplois/actualités: découverte des opportunités
- Profil: informations utilisateur et actions de compte

## 3) Parcours essentiels

### 3.1 Consulter un CRASC

1. Ouvrir l'annuaire
2. Choisir un CRASC
3. Consulter ses informations:
   - régions couvertes
   - OSC membres
   - actualités associées
   - (selon version) agenda et vidéos

### 3.2 Rechercher une organisation

1. Aller à la recherche/annuaire
2. Saisir un mot-clé
3. Filtrer par région si disponible
4. Ouvrir la fiche de résultat

### 3.3 Contacter PASCI

1. Ouvrir l'écran Contact
2. Renseigner les champs requis
3. Envoyer le formulaire
4. Attendre la confirmation d'envoi

Conseil: vérifier votre email et numéro avant envoi.

### 3.4 Faire une demande d'adhésion

1. Ouvrir l'écran Rejoindre
2. Remplir le formulaire d'adhésion
3. Vérifier les informations saisies
4. Soumettre la demande

### 3.5 S'inscrire à une formation

1. Ouvrir la liste des formations
2. Sélectionner une formation
3. Lire le détail (programme, modalité, prix)
4. Suivre la procédure d'inscription/paiement
5. Revenir via l'écran retour paiement si nécessaire

### 3.6 Vérifier un certificat

1. Ouvrir l'écran certificat
2. Entrer le code du certificat
3. Lancer la vérification
4. Lire le résultat affiché

## 4) Compte et connexion

### Connexion

1. Ouvrir l'écran Connexion
2. Saisir email et mot de passe
3. Valider

### Déconnexion

- Aller dans Profil
- Utiliser l'action de déconnexion

Si vous oubliez vos accès: utiliser le parcours "mot de passe oublié" si disponible.

## 5) Bonnes pratiques utilisateur

- Utiliser une connexion internet stable
- Mettre à jour l'application régulièrement
- Vérifier les informations avant toute soumission
- Ne jamais partager vos identifiants

## 6) Résolution de problèmes fréquents

### L'application ne charge pas les données

- Vérifier internet (Wi-Fi/4G/5G)
- Fermer et relancer l'application
- Réessayer après quelques secondes

### Le formulaire ne part pas

- Vérifier les champs obligatoires
- Vérifier le format email/numéro
- Réessayer avec un réseau plus stable

### Le paiement n'aboutit pas

- Vérifier votre connexion
- Vérifier le montant saisi
- Revenir sur l'écran de retour paiement

## 7) Support

En cas de blocage persistant:

1. Faire une capture d'écran de l'erreur
2. Noter l'heure et l'action réalisée
3. Contacter l'équipe support PASCI

Informations utiles à fournir:

- modèle de téléphone
- version de l'application
- version Android/iOS
- description courte du problème
